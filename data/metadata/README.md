# Dataset Metadata

## Dataset

**Colorectal Histology MNIST**

The dataset contains colorectal histopathology images represented as
28 × 28 pixel images.

## Dataset Statistics

* Total images: 5,000
* Number of classes: 8
* Images per class: 625
* Image dimensions: 28 × 28
* Pixel features: 784
* Target column: `label`

## Class Labels

The dataset contains the following class labels:

`1, 2, 3, 4, 5, 6, 7, 8`

Each class contains 625 images.

## Data Representation

Each image is represented as 784 pixel features:

`pixel0000` through `pixel0783`

The `label` column contains the corresponding class label.

## Data Source

Colorectal Histology MNIST dataset.

The raw dataset files are not stored in this repository due to dataset size.

## Purpose

This dataset is used for the few-shot colorectal histopathology
classification experiments in this research project.
